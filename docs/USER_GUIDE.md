# Varen CAD IDE 新手使用教程

这份教程面向第一次使用 Varen CAD 的人。目标是让你从零开始完成一次“上传手绘草图，生成 3D 模型并导出 STEP/STL”的完整流程。

## 1. 如何启动

Windows 上最简单的方式：

1. 双击桌面上的 `Varen CAD IDE` 快捷方式。
2. 如果没有快捷方式，运行项目根目录下的 `start-mechcad-pro.cmd`。
3. 浏览器会自动打开 `http://127.0.0.1:8001/`。

开发模式也可以使用：

```powershell
.\start-mechcad.cmd
```

开发模式访问 `http://127.0.0.1:5173/`。

## 2. 启动页

第一次打开会进入启动页，包含：

- `新建项目`：开始一次新的 AI 建模。
- `最近项目`：打开以前做过的工作，也可以重命名或删除。
- 右下角可以切换界面语言：中文 / English。

如果没有配置任何 AI 模型，系统仍会走本地示例路径，方便你先把整个流程跑通。

## 3. 认识主界面

界面按 SolidWorks 习惯布置：中间是 3D 工作区，右侧常驻 AI 助手，底部是结构抽屉。

- **顶部命令栏**：品牌与项目名、`新建` / `重命名` / `设置`、`撤销` / `重做`、`专注`（收起两侧面板放大视口）。
- **中央 3D 工作区**：视口工具条（适配 / 等轴 / 前视 / 俯视 / 右视 / 线框 / 正交 / 高画质）、ViewCube、
  左下剖切控制、坐标轴、面包屑与状态；右上角是 STEP / STL / 执行报告下载入口。
- **右侧 AI 助手**：常驻的对话式会话面板——消息流、内核工具卡片、可视化快照、审批卡 / 提问卡，
  底部输入框左侧 `＋` 可附草图，`Ctrl+G` 聚焦输入。
- **底部结构抽屉**：`特征树` / `属性` / `设计评审` / `过程` / `导出` 五个标签，点标签切换，最右 `▾` 收起。
- **底部状态栏**：坐标、模型状态、快捷键提示。

主界面长这样（深蓝夜空主题，右侧是对话式 AI 助手）：

## 4. 第一次生成模型（v0.10 对话式）

1. 在启动页点击 `新建项目`。
2. 右侧 `AI 助手` 面板是常驻的，直接在输入框里下指令（不需要打开抽屉）。
3. （可选）点输入框左侧 `＋` 附上手绘草图（PNG / JPG）——会话的**第一条消息**会自动带上它。
4. 输入例如：
   - "做一个 120×120×12 的法兰，中心 Ø30 通孔"
   - "外径 40mm，内径 30mm，长度 80mm 的套筒"
5. 按回车或点 `发送`。Agent 会在会话流里工作：模型文字逐字流式显示，每个工具调用是一张卡片（op / 参数 / 结果）。
6. 如果 Agent 需要确认，会话流顶部会弹出**审批卡 / 提问卡**，选择 **批准 / 改参 / 拒绝** 或直接输入答案。
7. **运行中也能继续说话**：聊天框始终可用，插话会在当前步骤结束后生效（例如"孔再大一点"）。
8. 3D 预览随几何变化自动刷新。

> 顶部 `生成 / 重算` 按钮和 `Ctrl+G` 只是把左侧表单里的描述作为一条会话消息发出——所有入口都是同一条对话。

## 5. 查看和导出模型

生成完成后：

- 中央 3D 视口会显示模型；右上角可直接下载 `STEP` / `STL` / 执行报告。
- 底部抽屉 `设计评审` 标签显示设计警告、制造建议、假设尺寸。
- 底部抽屉 `过程` 标签显示 AI 与 CAD Worker 的逐步执行记录。
- 底部抽屉 `导出` 标签是完整下载入口（含装配件与零件库）。

如果模型没有出现，先看底部 `过程` 和 `设计评审` 标签，通常原因包括：

- 仍有必答问题没有回答。
- 图纸缺少关键尺寸，严格模式下没有补数。
- CAD 执行失败，报告里会写明具体原因。

### 视口操作（v0.19–v0.21）

- 顶部工具条：`适配 / 等轴 / 前视 / 俯视 / 右视` 切换视角，`正交` 在工程视图与透视之间切换（默认正交），
  `高画质` 切换渲染档位（标准档降低像素比与棱线预算，大装配更流畅）。
- 左下 `剖切`：勾选后按 X/Y/Z 剖开模型，滑块移动剖切位置，`⇄` 翻转保留侧——适合看壳体内部结构。
- **右键任意零件**（SolidWorks 习惯）：`不透明 / 半透明 / 透明` 三档透明度、`隐藏零件`、`全部显示`。
  半透明后能直接看穿箱体看到内部齿轮；隐藏/透明过的零件会在视口底部出现
  `隐藏 N · 透明 N` 芯片，点 `恢复` 一键还原。
- 鼠标悬停零件会高亮并变成手型光标；右键**拖拽**是平移视图，不会误弹菜单。

## 6. 修改模型

### 通过属性面板修改

1. 在底部结构抽屉点 `特征树` 标签。
2. 在特征树里点击一个特征，例如 `through_hole`。
3. 切换到 `属性` 标签。
4. 修改尺寸后点击 `保存并重建`。

### 通过 AI 对话修改

在右侧 `AI 助手` 的聊天框里直接说，例如：

- “把中心孔改成 12mm”
- “删除顶部槽”
- “新增 4 个 M6 孔，分布在 30mm 半径的圆上”
- “把底板厚度改成 8mm”

Agent 收到后会基于当前特征上下文继续建模（这条会话历史会保留，重开项目也能回看），
3D 预览会自动刷新。若 Agent 正在运行，消息会排队到它当前步骤结束后生效。

### 撤销和重做

- `Ctrl+Z`：撤销。
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做。
- 顶部工具栏也有撤销 / 重做按钮。

## 7. 配置 AI 模型

点击顶部 `设置`，或按 `Ctrl+,` 打开设置中心，切到左侧 `模型` 标签。

Varen CAD 把模型分为两类（各一张卡片，分别配置）：

- 视觉模型：负责读取图纸，输出工程读图结果。
- 规划模型：负责把读图结果变成 FeaturePlan，也就是建模方案；agent 建模也用它。

每张卡片从上到下：

1. **厂商预置**：DeepSeek / Kimi / 智谱 / 通义 / 火山 / 硅基流动 / OpenAI / Anthropic / OpenRouter /
   Ollama 等一点即填 Base URL、协议和推荐模型；`自定义兼容端点` 可手填任意 OpenAI/Anthropic 兼容地址。
2. **协议**：`OpenAI` 或 `Anthropic` 分段开关（预置会自动选对）。
3. **Base URL / 模型名称**：模型名可点 `拉取模型` 直接从服务商拉列表（可搜索、可手填）。
4. **API Key**：只保存在本地服务端，界面永远只显示尾号徽章（`已保存 ····abcd`）；
   `👁` 显示/隐藏，输入新值即覆盖，清空后再保存则回退 `.env`。点 `获取密钥 ↗` 直达厂商控制台。
5. **生成参数**（折叠）：温度、最大输出 token、超时、重试次数——留空表示跟随 `.env` 与代码默认值，
   点 `用默认` 可清除自定义值。
6. **测试连接**：会真实发一次最小请求，返回**延迟毫秒数、端点、模型回显**，便于判断是网络、鉴权还是模型名的问题。

右上角还有 `导出 JSON` / `复制 .env`（密钥自动脱敏），以及 `强制使用真实 API` 开关。
改完记得点 `应用配置`（或 `Ctrl+S`）保存到当前项目。

如果只是体验流程，可以不配置，直接使用本地示例路径。

## 8. 模式说明

在设置中可以选择工作模式：

### 严格模式

- 只使用图纸上明确标注或用户确认的尺寸。
- 缺失尺寸时不会猜测，而是提问。
- 适合精度要求高的零件。

### 智能模式

- 在机械常识和图形比例基础上进行合理设计。
- 有三种自主程度：
  - `limited_fill`：工程保守设计，只补低风险概念尺寸。
  - `aggressive_fill`：概念快速生成，自动处理常见孔、槽、凸台、阵列。
  - `full_autonomous`：全自主方案设计，可以主动增加合理特征。

智能模式的所有推断都会写入假设和设计评审，不会悄悄使用。

## 9. 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+G` | 生成 / 重新计算模型 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 关闭设置中心 / 右键菜单 |

## 10. 常见问题

### 模型和图纸不一致

先看底部 `设计评审` 标签里的假设尺寸和未解决项。如果 AI 猜了尺寸，而你希望精确建模，请：

1. 在描述里把已知尺寸写完整。
2. 回答 AI 的所有确认问题。
3. 必要时切换到严格模式。

### 生成按钮看起来像卡住

先看右侧 `AI 助手` 面板是否有待回答问题。严格模式遇到缺失尺寸时会停在等待确认状态，这不是卡死。

### CAD 报错

打开底部 `过程` 标签或 `导出` 里的执行报告。报告会写明是哪个特征失败、跳过原因或布尔运算错误。旧模型不会伪装成本次成功结果。

### 3D 视图是空的

- 确认生成已经完成。
- 点视口工具条的 `适配` 按钮。
- 检查底部 `过程` 标签是否有失败信息。
- 如果页面很久没有刷新，按 `F5` 重新加载项目。

## 11. 一次完整的练习

建议用这个最小案例熟悉流程：

1. 新建项目。
2. 不传图片，只在描述里写：“一个 60mm x 30mm x 10mm 的底板，四角各有一个 5mm 通孔，孔中心距边缘 8mm。”
3. 点击生成。
4. 如果 AI 提问，依次回答。
5. 生成后在 3D 视口里旋转查看（右键零件还能调透明度/隐藏）。
6. 下载 STEP 文件，用任意 CAD 查看器打开验证。

做完这一步，你就已经掌握了 Varen CAD 的核心工作流。
