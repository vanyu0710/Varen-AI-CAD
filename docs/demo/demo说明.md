# Varen CAD Demo 说明

> 一句话定位：**Varen CAD 是一个会留下证据的 AI 机械 CAD 工作台。**
> 它不是把一句话变成一张“看起来像 CAD”的图片，而是先调研、提问、出 BOM，经用户批准后逐件生成真实 B-Rep 几何，再执行几何验证与装配干涉检查，最终导出可被其他 CAD 软件打开的 STEP。

---

## 1. 创意：把“AI 生成”变成“可审查的工程过程”

传统 AI 生成工具的问题是：结果看起来很完整，但工程师无法确认它为什么这么做、哪些尺寸是假设、几何是否真的合格。

Varen CAD 的核心创意是：

1. **先像工程师一样工作**
   - 调研与工程计算先行；
   - 信息不足时结构化提问；
   - 输出 BOM 与建模计划，等待用户批准；
   - 批准后才允许修改 CAD 几何。

2. **真实 CAD 几何，不是渲染图**
   - 使用 OpenCascade 内核生成 B-Rep；
   - 保留特征树、参数、操作历史；
   - 导出 STEP / STL，可进入下游 CAD、仿真或原型流程。

3. **错误不能被包装成成功**
   - 单实体、孔径、数量、位置、参数回放等都有几何契约；
   - 装配导出前检查干涉；
   - 硬碰撞或计算错误会阻断交付；
   - 报告中的 `production_ready` 始终为 `false`，最终制造前必须人工工程复核。

4. **知识必须可溯源**
   - 密封圈、紧固件、铝型材等领域知识采用 evidence-first 设计；
   - 用户可以上传资料；
   - 只有经过人工审核发布的事实才能进入建模；
   - 未解决冲突不会进入 CAD。

5. **本地优先、过程留痕**
   - 项目、会话、特征历史、工具调用、验证结果和交付物保存在本地；
   - 模型端点可由用户自行配置；
   - 便于机械、机器人和硬件团队在数据敏感场景中试用。

## 2. 主要功能

### 2.1 AI 建模 Agent 工作流

- 用户用自然语言描述零件或装配需求；
- Agent 展示思考、规划、调研、工具调用与当前阶段；
- 不明确处会发出结构化提问，而不是悄悄猜数；
- 输出 BOM 与建模步骤，等待审批；
- 逐件建模、逐件归档，避免“一次性黑盒生成”。

### 2.2 真实 CAD 内核

- 支持 OpenCascade B-Rep 建模；
- 生成参数化特征与操作历史；
- 支持特征树查看、修改参数、删除特征、重放与撤销/重做；
- 导出 STEP 与 STL，而不是仅生成图片或三角网格。

### 2.3 专业 CAD 工作区

- 中间为 3D 视口，支持等轴、前视、俯视、右视、剖切、正交/透视、线框与高画质模式；
- 支持装配零件选择、隐藏、透明、单独显示与导出；
- 左侧/底部结构面板可查看：
  - 特征树；
  - 属性；
  - 材料；
  - 工程知识；
  - 设计评审；
  - 过程记录；
  - 导出产物。

### 2.4 材料与工程审查

“材料”标签用于把当前零件库中的视口渲染材质按组展示，并重点审查零件和装配体。

它会明确区分三类信息：

| 类型 | 系统行为 |
| --- | --- |
| 实测/程序检查结果 | 例如实测体积、几何验证状态、装配干涉数量 |
| 渲染代理 | 例如 `steel`、`cast_iron`、`aluminum` 等视口材质键 |
| 待人工工程确认项 | 例如材料规格、配合豁免、制造可行性 |

重要约束：

> `material` 只是视口渲染代理，不是工程材料规格。Varen CAD 不会凭空输出 45 钢、6061-T6、屈服强度、硬度、密度等未经验证数据。

重点零件审查包括：

- 版本；
- 功能角色；
- 设计依赖；
- 实测体积；
- 验证状态；
- STEP / STL 是否缺失；
- 是否参与硬碰撞或计算错误；
- 是否缺少角色、依赖或装配位姿。

装配体审查包括：

- 装配零件数；
- 检查零件对数；
- 硬碰撞数量；
- expected fit / expected mesh 豁免；
- superseded 或 BOM 外零件；
- 装配 STEP 与 JSON 报告入口。

### 2.5 Evidence-first 工程知识库

- 支持上传 PDF、Word、Excel、CSV、文本、图片、STEP / STL 等资料；
- 保存原件与 SHA256；
- 提取出的知识必须人工审核；
- 发布后才可供搜索和建模使用；
- 冲突证据会阻断，不会静默择优。

### 2.6 子代理研究计划

用户可以针对某个零件、装配或工程问题生成研究计划。子代理只负责：

- 调研问题拆解；
- 设计要点；
- 风险清单；
- 参数实验建议；
- 待确认资料。

子代理不直接修改 CAD 模型，避免研究过程绕过建模门控。

### 2.7 装配与交付

- 按 BOM 放置零件；
- 生成装配 STEP；
- 执行零件对干涉检查；
- 硬碰撞阻断导出；
- expected fit / expected mesh 必须显式声明；
- 生成装配报告、渲染图和执行报告；
- 所有假设与失败门控进入交付报告。

## 3. 使用方式

### 3.1 启动

Windows 安装包方式：

1. 下载并解压 Varen CAD；
2. 运行 `VarenCAD.exe`；
3. 打开设置，配置 OpenAI-compatible 模型端点；
4. 新建项目。

源码方式：

```powershell
git clone https://github.com/vanyu0710/Varen-AI-CAD.git
git clone https://github.com/vanyu0710/mechcad-kernel.git
cd Varen-AI-CAD
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt build123d==0.11.1 cadquery-ocp-novtk==7.9.3.0
.\start-mechcad-pro.cmd
```

### 3.2 最小演示：单零件

新建项目后，在右侧 AI 助手输入：

```text
做一块 120×120×12 mm 的法兰，中心 Ø30 通孔，Ø90 螺栓圆上均匀分布 6 个 Ø8 孔。
报告所有假设；验证失败时拒绝导出。
```

演示要点：

1. Agent 开始规划与建模；
2. 如有缺失信息，会出现提问卡；
3. 特征树显示孔、阵列、基准特征；
4. 视口实时更新；
5. 导出 STEP / STL / 执行报告。

### 3.3 进阶演示：多零件装配

可以使用：

```text
设计一个 1:100 三级齿轮减速器，输出装配 BOM 和逐件建模计划。
关键零件完成后导出装配 STEP，并报告所有干涉。
```

演示流程：

1. Agent 调研传动比、中心距等计算；
2. 输出 BOM 与位姿计划；
3. 用户批准计划；
4. Agent 逐件建模并归档；
5. 执行装配干涉检查；
6. 导出装配 STEP 与报告。

### 3.4 材料与装配审查演示

在底部结构面板打开 **材料** 标签：

1. 查看材料分组：
   - `steel`
   - `cast_iron`
   - `aluminum`
   - 等；
2. 阅读提示：
   - 这些是渲染材质代理，不是工程规格；
3. 查看“重点零件审查”：
   - 阻断项；
   - 警告项；
   - 版本、角色、依赖与实测体积；
4. 查看“装配体审查”：
   - 装配零件数；
   - 检查零件对；
   - 硬碰撞；
   - fit / mesh 豁免；
   - superseded 排除项；
5. 点击装配 STEP 或装配报告链接。

### 3.5 知识库演示

在 **知识** 标签中：

1. 上传一份密封圈、紧固件或铝型材资料；
2. 查看文档处于待审核状态；
3. 提取证据并人工审核；
4. 发布后搜索该证据；
5. 生成子代理研究计划。

注意：上传不等于知识可用。只有人工审核发布的证据才会进入建模链路。

## 4. 推荐 Demo 脚本

### 4.1 60 秒展示

| 时间 | 画面 | 讲解 |
| --- | --- | --- |
| 0–10s | 启动页与主工作区 | “这是一个本地优先的 AI CAD 工作台。” |
| 10–20s | 输入法兰任务 | “一句话输入，Agent 会先规划，而不是直接黑盒生成。” |
| 20–35s | 特征树、视口、参数修改 | “生成的是真实 B-Rep 几何，特征树和参数都可改。” |
| 35–45s | 材料 / 重点零件 / 装配审查 | “材料只是渲染代理，工程规格必须来自已审核证据。” |
| 45–55s | 装配 STEP 与报告 | “硬碰撞会阻断交付，导出的 STEP 可以用其他 CAD 打开。” |
| 55–60s | 结尾 | “Varen CAD 的价值不是宣称成功，而是留下可审查的证据。” |

### 4.2 3 分钟展示

1. **0:00–0:30 问题定义**
   - 展示传统 AI 生成无法审计的问题；
   - 引出 Varen CAD 的核心原则：计划审批、真实几何、验证门控。

2. **0:30–1:00 需求与规划**
   - 输入需求；
   - 展示思考状态、提问卡、BOM 计划；
   - 强调用户批准是硬门控。

3. **1:00–1:40 建模与编辑**
   - 观察特征树；
   - 修改一个参数并重放；
   - 展示视口、剖切、透明与隐藏。

4. **1:40–2:20 工程审查**
   - 打开材料标签；
   - 演示渲染材质代理警告；
   - 查看重点零件阻断/警告；
   - 查看装配硬碰撞、fit / mesh 豁免和排除项。

5. **2:20–3:00 交付与边界**
   - 下载 STEP / STL / 报告；
   - 说明 Varen CAD 不承诺无人值守制造；
   - 强调 `production_ready=false`，制造前必须人工工程复核。

## 5. 演示红线

讲解时请避免以下说法：

- “可以自动制造”；
- “等同于 SolidWorks”；
- “无人值守完成工程设计”；
- “AI 保证结构安全”；
- “材料规格自动正确”。

推荐说法：

- “生成可检查的真实 CAD 几何”；
- “验证失败会阻断交付”；
- “假设和错误会写进报告”；
- “知识必须来自已审核证据”；
- “制造前需要人工工程复核”。

## 7. 一页总结

**Varen CAD 的 demo 重点不是“AI 画了一个模型”，而是：**

1. 用户先批准计划；
2. Agent 逐件生成真实 CAD 几何；
3. 特征、参数、假设和过程可回放；
4. 几何验证和装配干涉会阻断不合格结果；
5. 工程知识必须证据可溯；
6. 材料分组不冒充材料规格；
7. STEP 可以交给工程师继续检查；
8. 系统诚实报告边界，不把概念设计包装成制造放行。
