# 旗舰视频脚本 — 90 秒（"错误会被抓住"版）

**原则**：不展示一次完美成功。必须包含"错误出现 → 门控拒绝 → 修复 → 放行"的完整弧。
**素材**：1:100 减速器真实运行录屏（一镜到底后剪辑），benchmark JSON 同屏展示。

| 秒 | 画面 | 字幕/旁白 |
|---|---|---|
| 0–8 | 输入框敲入"给我设计个 1:100 的变速箱"；agent 开始流式回复 | 一句话。13 分钟后，你会看到什么？ |
| 8–18 | 快速闪：调研卡片（传动比拆分 85/17×85/17×68/17=100）、ask_user 卡片、BOM 计划审批卡（8 件 + 位姿） | 它先像工程师一样算账、问你问题、给出零件清单等你点头 |
| 18–30 | 逐件建模：齿轮生成特写（真渐开线齿）、会话流工具卡 + 四视角快照滚动 | 34 个受控内核操作，每一步留痕、可回放、可改参数 |
| 30–48 | **戏剧点**：某步报错卡（INTERFERENCE_BLOCKED / FEATURE_CONTRACT_MISMATCH 真实片段），红色拒绝，agent 读回错误、修改、重试 | 中途它试图交付一个不合格的零件——门控拒绝归档，把证据甩回给它 |
| 48–66 | 返工动画：轴/齿轮位姿修改 → 复检通过 → 归档打勾 → export_assembly | 它会抓住自己的错误，并且不给错误结果盖章 |
| 66–80 | 装配四视图 + 干涉报告：28 对全查 / 2 对啮合豁免 / **硬碰撞 0**；STEP 文件在 FreeCAD/SolidWorks 打开特写 | 8 件 / 53 步 / 758 秒 / 干涉 0。打开 STEP 的，是你手上的 CAD |
| 80–90 | 终端敲 `run_benchmark.py --all`，results 目录滚动 + GitHub 页面 | 开源，本地运行。失败样本也公开。申请封闭 Beta → 见简介 |
