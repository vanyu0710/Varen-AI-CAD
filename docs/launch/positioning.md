# Varen CAD 定位与表述纪律（对外口径唯一来源）

**生效日期**：2026-09-16 · 适用于：README、落地页、视频、文章、Issue 回复、社交媒体、销售对话。
所有对外物料发布前按本文件过一遍禁用词。

## 品类

**可审计的机械设计 Agent（Auditable Mechanical Design Agent）**。
不再使用"CAD 领域的 Codex"作为主定位（该比喻已拥挤：Adam=v0 of CAD、BuildCAD=CAD 的 Cursor）。
"本地优先 + 硬门控 + 完整审计链"是定位的三个支点。

## 定位语

| 场景 | 文案 |
|---|---|
| 中文主标题 | 会交付证据的机械设计 Agent。 |
| 中文副标题 | 从一句话到参数化装配：每一步可回放，每个关键结果可检查，碰撞与契约不过关就不交付。 |
| 中文安全版（正式场合/合同） | 面向概念设计与快速原型的本地 AI CAD Agent，输出可继续编辑的 B-Rep、参数历史与 STEP 装配。 |
| 英文主标题 | An auditable, local-first CAD agent for parametric mechanical assemblies. |
| 英文副标题 | It plans, builds, checks, and explains every step — and refuses delivery when validation fails. |

## 三个信息支柱（每条物料至少命中一个）

1. **Build**：调研 → 提问 → BOM 计划 → 逐件建模 → 装配交付（多零件长任务，不是单件玩具）。
2. **Verify**：孔语义契约 / 单实体复检 / 硬碰撞阻断 / 同名原子换版——成功由程序判定，不由模型文字判定。
3. **Audit**：每一步工具调用、测量、假设、失败与修复完整留痕；execution_report 含假设与需复核项。

## 可引用证据（截至 v0.21，全部可复跑）
- 1:100 三级减速器：真实 LLM 53 步 / 758s 一次通过，8 件，硬碰撞 0（v0.16 验收记录）
- 首轮曾被硬碰撞门拦下、模型自行返工轴/齿轮位姿后放行（"门是真的会拦"的实证）
- 5 挡手动变速器总成：26 件 / 325 对干涉全查 / 程序审计 FAIL 0（v0.17–0.18）
- 测试规模：后端 468 + 前端 92 + 内核 ~390，含真实 worker E2E 与诊断/门控回归
