- **Artifact**: `VarenCAD-win64-0.22.4-beta.zip`

## Highlights

### 1. User-confirmed automatic updates

Varen CAD can now install a verified newer GitHub release after you explicitly click **Update**.

- startup update checks remain non-intrusive and can be disabled;
- the package is downloaded only after confirmation;
- the ZIP and SHA256 files are downloaded and the archive hash is verified;
- cancellation, incomplete downloads, and hash mismatches stop the update;
- the new version is unpacked to a staging area and never overwrites the running app;
- user data under `work/` and your local `.env` are preserved;
- the update transaction has rollback handling;
- the app asks you to restart and never kills unrelated processes.

There is no silent background update, startup service, or forced restart.

### 2. Reliable STEP/STP/STL delivery

Model export and download links now follow the manifest and only enable when a real artifact exists.

- `.stp` is accepted as a STEP alias and writes standard `ISO-10303` STEP content;
- top-level STEP links use `model.step`, falling back to a project assembly STEP;
- STL, OBJ, execution reports, per-part STEP/STL, assembly STEP, and assembly reports use real artifact paths;
- Unicode filenames are URL-encoded and served with explicit download filenames;
- download names keep the project, part, and format information.

### 3. Save As for model files

Export links now use the browser save dialog where supported.

- you can edit the suggested filename;
- you can choose the destination directory;
- data is streamed from the service into the selected file;
- cancellation writes nothing;
- unsupported browsers fall back to a normal download.

### 4. Windows kernel-worker launch fixes

The packaged CAD kernel worker now starts reliably on Windows.

- the sibling MechKernel repository is resolved with the correct path level;
- missing kernel repositories are rejected before `Popen`;
- packaged mode uses `CREATE_NO_WINDOW` instead of the invalid `windowsHide` argument;
- errors are explicit rather than surfacing as a generic directory-name failure.

### 5. Better modeling diagnostics and housing audits

Complex concept-modeling runs now expose more actionable failures.

- housing audits use the current transient geometry and BOM pose;
- audit internals respect BOM dependencies;
- assembly interference results expose pair-level evidence and calculation errors;
- bolt-hole edge-distance checks no longer misread the relevant housing walls.

### 6. Model-console regression fix

Model connection probes are correctly excluded from pytest collection, so the model-console test suite now runs reliably. Multi-provider configuration, active-role resolution, and connection diagnostics remain covered by tests.

## Installation

1. Download `VarenCAD-win64-0.22.4-beta.zip`.
2. Verify `VarenCAD-win64-0.22.4-beta.sha256` with:
   ```powershell
   Get-FileHash .\VarenCAD-win64-0.22.4-beta.zip -Algorithm SHA256
   ```
3. Extract to a writable folder.
4. Run `VarenCAD.exe`.
5. Optional: configure models in **Settings → Model**, or copy `.env.example` to `.env` for source-code runs.

## Known limitations

- Automatic updates apply only after user confirmation; there is no background service or forced restart.
- The browser Save As dialog requires a Chromium/WebView2 environment that supports the File System Access API. Other browsers use normal downloads.
- Gear placement is manual; there is no meshing solver, kinematics simulation, or general mate solver.
- Stepped holes are implemented in MechKernel but are not yet part of the high-level Varen feature schema.
- Semantic selection and BRep measurement remain single-part only.
- This beta does not provide complete 2D drawings, sheet metal, thread standards, general surface modeling, or a full assembly mate solver.
- `production_ready` remains `false`; outputs require engineering review before manufacturing use.
