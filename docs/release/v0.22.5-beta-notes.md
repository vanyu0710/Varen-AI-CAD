## Highlights

### 1. Security hardening

This release includes the external security audit fixes from [PR #10](https://github.com/vanyu0710/Varen-AI-CAD/pull/10), plus an additional guard for real model calls.

- a custom project Base URL must provide its own API key; Varen CAD will not implicitly send the local `.env` key to a different host;
- the same rule now applies not only to connection tests and model listing, but also to real chat and tool calls;
- model endpoints reject non-HTTP(S) schemes and known cloud metadata addresses, including trailing-dot variants;
- project WebSockets verify browser origins before accepting a connection;
- agent modeling scripts receive an additional static safety pre-check in the app layer;
- artifact requests validate run IDs and constrain resolved paths to the artifact root.

No credentials are included in the release package.

### 2. Failed-run geometry rescue

When a model or agent run fails after real geometry has been built, Varen CAD now attempts a bounded rescue export.

- the kernel must still be alive;
- the current BRep volume must be positive and finite;
- STEP and STL are written atomically;
- existing usable artifacts are never overwritten;
- the failed or partial run is not reclassified as successful.

This preserves inspectable work for troubleshooting without weakening the delivery gates.

### 3. Agent conversation ordering

Approval-wait messages now keep the OpenAI-compatible tool-call order valid:

```text
assistant(tool_call) → tool_result → user
```

This prevents user interjections during a pending approval from causing HTTP 400 / code 10013 failures.

### 4. Multi-part project inspection

The viewport now has an explicit assembly/current-part switch, and the assembly panel adds:

- part search;
- visible and interference filters;
- per-part solo view;
- show-all recovery;
- part count and visibility status.

This makes larger concept assemblies easier to inspect without changing geometry or validation.

### 5. Nested MechKernel source layout support

The backend and launcher now detect MechKernel checkouts at several parent levels. Missing or incomplete kernel repositories fail early with `KERNEL_REPO_MISSING` instead of surfacing as a generic Windows directory error.

## Installation

1. Download `VarenCAD-win64-0.22.5-beta.zip`.
2. Verify `VarenCAD-win64-0.22.5-beta.sha256` with:
   ```powershell
   Get-FileHash .\VarenCAD-win64-0.22.5-beta.zip -Algorithm SHA256
   ```
3. Extract to a writable folder.
4. Run `VarenCAD.exe`.
5. Optional: configure models in **Settings → Model**, or copy `.env.example` to `.env` for source-code runs.

## Known limitations

- Varen CAD remains a concept-design and rapid-prototyping beta; `production_ready` is always `false`.
- Outputs require engineering review before manufacturing use.
- No complete 2D drawing workflow, sheet metal, thread standards, general surface modeling, or full assembly mate solver.
- Gear placement is manual; there is no meshing solver or kinematics simulation.
- Stepped holes exist in MechKernel but are not yet exposed in the high-level Varen feature schema.
- Automatic updates require user confirmation and a manual restart; there is no silent background update.
