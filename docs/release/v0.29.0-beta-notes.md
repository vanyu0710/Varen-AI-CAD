# Varen CAD v0.29.0-beta

> 封闭 Beta：概念设计与快速原型工具。`production_ready` 恒为 false；投产前所有尺寸与假设必须由工程师复核。

## 本版重点：Varen Agent 增强引擎 + 联网搜索

- **增强 Agent 引擎**：每个项目一个内嵌运行时进程，具备联网检索、网页读取、项目文件读取、
  子代理（researcher / dfm / verifier）、技能与上下文压缩；模型端点继续使用规划模型配置
  （DeepSeek 官方 Messages 兼容端点或任意 OpenAI 兼容端点）。
- **CAD 工具经 MCP 暴露**：52 个内核 op + 12 个合成工具 + 搜索/文件工具；所有内核操作仍走
  后端计划门禁、破坏性审批、快照与产物提交，不绕过既有安全边界。
- **联网搜索**：设置新增「联网搜索」页，支持 Tavily 兼容端点和 DeepSeek Search API
  （`/v1/tools/search`，Bearer Key）；未配置时回退官方云端。网页抓取使用本地 SSRF 安全实现。
- **工具过程可见**：聊天中的搜索/抓取工具卡显示查询、结果数、可点击来源和真实错误；
  搜索不可用时可直接从聊天区打开搜索设置。修复了增强引擎工具卡名称/参数空白的真实事件解析问题。
- **默认引擎**：新项目默认增强引擎；经典引擎仍可在设置中选择，运行时启动失败自动回退经典。
- **图片直传**：规划模型支持视觉时，草图/图纸作为多模态图片直接送入规划模型，不再先做视觉预描述。
- **模型与设置**：模型控制台支持云端/自定义双模式、供应商档案、模型列表拉取、测试连接；
  联网搜索密钥只写入本机 `.env`，API 只回显尾号。

## 安装 / 升级

1. 下载 `VarenCAD-win64-0.29.0-beta.zip` 和同页 `.sha256` 文件。
2. 校验：`Get-FileHash .\VarenCAD-win64-0.29.0-beta.zip -Algorithm SHA256`，与 `.sha256` 内容比较。
3. 解压后运行 `VarenCAD.exe`；也可以使用同目录 `VarenCAD-setup-0.29.0-beta.exe` 安装。
4. 首次启动后到「设置 → 模型」配置规划模型；需要联网检索时到「设置 → 联网搜索」配置
   Tavily 兼容端点或 DeepSeek Search API Key。

增强引擎的运行时 sidecar 已随包分发；不需要系统安装 Node。

## 已知限制（如实告知）

- Beta 安装包未代码签名，Windows SmartScreen 会提示未知发布者。
- 增强引擎首次启动会初始化运行时/MCP/内核，冷启动可能明显慢于后续请求。
- DeepSeek Search 需要有效 API Key，搜索请求按 DeepSeek 计费；未配置时搜索工具会如实报错。
- 部分网站会拒绝本地抓取（403/404/超时）；工具会显示真实错误，不伪造正文。
- 运行时进程名仍为 `node.exe`；生产部署如要求严格进程名需另做 launcher。
- 部分内核能力仍明确拒绝（复杂螺纹/钣金/部分曲面），以真实错误为准。
- 本版不承诺制造级交付；所有工程输出必须人工复核。
